# A top-level navigation.
#
# Measured 2026-09-08 from Chrome 152, Edge 152 and Brave 152 on Windows,
# each started headless, against local servers that keep headers in arrival
# order: plain HTTP/1.1, HTTP/1.1 over TLS, and HTTP/2 with the HPACK block
# decoded field by field. All three browsers sent this order on all three.
#
# One file covers both protocols because the check skips any header the
# request or this file lacks: over HTTP/1.1 the browser sends host and
# connection and no priority, over HTTP/2 it sends priority and no host or
# connection. Over HTTP/2 the pseudo-headers come first, as
# :method :authority :scheme :path; this checker does not read them.
# sec-gpc is Brave's and the other two do not send it.
#
# Not measured: any other major, any other platform. A proxy or a HAR export
# may not keep the order the browser used. Hold a request against this file
# only when the order it shows is the order that reached the wire.
host
connection
sec-ch-ua
sec-ch-ua-mobile
sec-ch-ua-platform
upgrade-insecure-requests
user-agent
accept
sec-gpc
sec-fetch-site
sec-fetch-mode
sec-fetch-user
sec-fetch-dest
accept-encoding
accept-language
priority
